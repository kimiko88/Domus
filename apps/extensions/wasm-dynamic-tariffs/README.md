# Day-Ahead Dynamic Energy Tariffs Engine (WASI)

Aggiornamento quotidiano dei prezzi zonali dell'energia elettrica (PUN italiano, Nord Pool scandinavo, EPEX Spot centro-europeo).

- **Sicurezza di Rete**: Esegue chiamate HTTP esclusivamente verso le API pubbliche dei mercati dell'energia, con isolamento sandbox WASI.
