# Local Acoustic Event & Emergency Siren Classifier (WASI)

Classificazione acustica edge con modelli quantizzati (WASI-NN) per il riconoscimento immediato di sirene salvavita (T3 fumo, T4 monossido), rottura vetri e pianto bambini.

- **Privacy Totale**: Il flusso audio non viene mai registrato su disco né inviato a server cloud.
- **Latenza**: Inferenza locale in <15 ms.
- **Licenza**: Apache-2.0 Open Source.
