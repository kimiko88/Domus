# Meshtastic & LoRa Off-Grid Emergency Beacon (WASI)

Plugin della community per l'integrazione di reti radio LoRa a lungo raggio (868 MHz / 915 MHz).

## Finalità
Permette a Domus di inoltrare messaggi salvavita verso dispositivi LoRa tascabili (T-Beam, Heltec) della famiglia anche durante blackout totali di rete Internet e cellulare.
