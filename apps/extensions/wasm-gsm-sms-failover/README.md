# Local GSM/LTE AT-Command Modem & SMS Failover (WASI)

Plugin community per il controllo di modem 4G/LTE (SIMCom, Quectel) tramite comandi seriali AT. Permette di inviare SMS d'allarme e stabilire connessioni di backup via rete mobile se la rete fissa subisce un guasto.
