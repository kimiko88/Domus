# Wireless M-Bus & OMS Smart Metering (WASI)

Plugin WASI ad alte prestazioni per la ricezione e decodifica di telegrammi OMS su frequenza 868 MHz da contatori di calore, acqua e gas.

## Caratteristiche
- **Isolamento di Memoria**: Decodifica frame radio crittografati AES-128 senza rischi di buffer overrun.
- **Supporto OMS v3 / v4**: Supporto per contatori Diehl Hydrus, Kamstrup Multical, B-Meters e Sontex.
