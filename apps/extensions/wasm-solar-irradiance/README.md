# Solar Irradiance & Clear-Sky Local Predictor (WASI)

Previsione della produzione solare fotovoltaica a 24–48 ore eseguita localmente su Domus OS tramite equazioni astronomiche ad alta precisione, senza dipendenza da server esterni o connessione a internet.

- **Modello Matematico**: Clear-Sky Ineichen / Perez
- **Licenza**: Apache-2.0
- **Esecuzione**: Sandboxed WASI con zero chiamate di rete esterne.
