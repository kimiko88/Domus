# mmWave Radar Point-Cloud DSP & Micro-Presence Filter (WASI)

Elaborazione ad alta velocità di segnali radar FMCW a 24 GHz e 60 GHz (LD2410, MR60BHA1) per la rilevazione di micro-presenza (respiro da fermi) e allarme caduta persone vulnerabili.

- **Sicurezza Biometrica**: Tutti i dati radar rimangono confinati nel sandbox lineare WASI; nessun dato esce dal dispositivo.
